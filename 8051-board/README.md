# 8051 Development Board

**What it is:** A development board for the 8051 microcontroller, designed in OrCAD from schematic to Gerber files.

**Why:** To learn the full PCB design flow (schematic, footprints, layout, routing, manufacturing files) by following the Pantech Academy "Internship on PCB Design" course.

**Tools:** OrCAD [version], Pantech Academy PCB Design course.

**Board contents (from the course design):** power supply (3.3 V and 1.8 V), reset circuit, crystal, port 0 pull-ups, UART through an FT232 USB-to-serial chip, programming header, LED and LCD interfaces, temperature sensor and buzzer, seven-segment display, relay and stepper motor drivers.
